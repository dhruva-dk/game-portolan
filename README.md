# Portolan

A battle royale of sailing ships on a small planet, with a racing team to run between matches.

- **Plan:** `docs/PLAN.md` is the plan and the standing instructions. Read it first.
- **Screenshots:** `captures/` (gitignored), one folder per group, named by date and subject, e.g. `captures/2026-11-24-lobby-layout/`. Older shots are in `captures/old/`.
