# Credits

Every mesh, ship, island, creature, sound and note is generated in code, and so is the interface's parchment (paper,
torn edges, the chart). The game bundles surface textures and fonts from the sources below. To add an entry, append
one line: `- <name> — <source URL> — <author> — <licence> (<use>)`.
Licences: CC0 = https://creativecommons.org/publicdomain/zero/1.0 · OFL = https://openfontlicense.org ·
MIT = https://opensource.org/license/mit · Apache-2.0 = https://www.apache.org/licenses/LICENSE-2.0
